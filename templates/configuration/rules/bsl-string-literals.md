# BSL: строковые литералы

При написании кода 1С:Предприятие используй синтаксис строковых литералов BSL, а не правила экранирования из JSON, JavaScript, Python и других языков.

## Кавычки

Строковый литерал ограничивается двойными кавычками `"..."`.

Кавычка внутри строкового литерала экранируется **удвоением**, а не обратным слешем:

```bsl
Правильно = "ООО ""Ромашка""";
Неправильно = "ООО \"Ромашка\"";
```

Никогда не заменяй `"` внутри BSL-строки на `\"`.

## Многострочные строки

Для многострочной строки используй синтаксис BSL с `|` в начале продолжающих строк:

```bsl
Текст =
"Первая строка
|Вторая строка
|Третья строка";
```

Особенно часто этот синтаксис используется для `Запрос.Текст`:

```bsl
Запрос.Текст =
"ВЫБРАТЬ
|    Номенклатура.Ссылка,
|    Номенклатура.Наименование
|ИЗ
|    Справочник.Номенклатура КАК Номенклатура";
```

Не преобразовывай этот синтаксис в `\n` или обычный перенос строк по правилам JSON/JavaScript.

## Вложенные контексты

Всегда различай уровни экранирования.

Например, если BSL-код помещается внутрь JSON, сначала формируется корректный BSL, и только затем он экранируется по правилам JSON.

BSL:

```bsl
Текст = "ООО ""Ромашка""";
```

JSON-представление этого кода может требовать дополнительного JSON-экранирования. Не смешивай эти два уровня.

## Проверка

После изменения строковых литералов особенно проверяй:

* парность открывающих и закрывающих `"`;
* использование `""` для кавычек внутри строки;
* `|` в продолжениях многострочных строк;
* тексты запросов `Запрос.Текст`;
* вложенные строки в `НСтр()`, JSON и других форматах.

При сомнении ориентируйся на синтаксис BSL и документацию платформы, а не на правила экранирования из другого языка.
