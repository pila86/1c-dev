# Структура модуля 1С

При создании и изменении модуля соблюдай стандартный порядок областей. Новый код помещай в существующую подходящую область.

## Общие правила

* Используй `#Область ... #КонецОбласти`.
* Не создавай области внутри процедур и функций.
* Не используй комментарии вместо областей.
* Не создавай отдельную область для каждого метода без необходимости.
* Не меняй порядок стандартных областей без причины.

## Модуль объекта

```bsl
#Область ОписаниеПеременных
#КонецОбласти

#Область ПрограммныйИнтерфейс
#КонецОбласти

#Область ОбработчикиСобытий
#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
#КонецОбласти

#Область Инициализация
#КонецОбласти
```

Обработчики событий размещай только в `ОбработчикиСобытий`. Вспомогательную логику размещай в `СлужебныеПроцедурыИФункции`.

## Общий модуль

```bsl
#Область ПрограммныйИнтерфейс
#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
#КонецОбласти
```

## Модуль формы

```bsl
#Область ОбработчикиСобытийФормы
#КонецОбласти

#Область ОбработчикиСобытийЭлементовШапкиФормы
#КонецОбласти

#Область ОбработчикиСобытийЭлементовТаблицыФормыИмяТаблицы
#КонецОбласти

#Область ОбработчикиКомандФормы
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
#КонецОбласти
```

Для каждой таблицы формы используй отдельную область `ОбработчикиСобытийЭлементовТаблицыФормы<ИмяТаблицы>`.

При добавлении нового метода сначала определи его назначение и помести его в соответствующую область. Не создавай новую область, если подходит существующая.
