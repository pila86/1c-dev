## Optional MCP: bsl-search

Если в сессии доступен MCP-сервер `bsl-search` — используй его для поиска
реальных реализаций BSL в корпусе. Если сервер недоступен — не выдумывай код
и не притворяйся, что вызвал tool.

### Когда звать

- Поиск похожих процедур/функций / паттернов в корпусе конфигураций и БСП.
- Подбор примеров реализации по задаче или сигнатуре.
- Опора на корпус вместо «кода с нуля», когда нужна типичная практика 1С.

### Когда не звать

- Вместо чтения текущего workspace / `metadata.*` проекта.
- Вместо точного API lookup (`docs.*`, `bsl-language-server`).
- Не execute BSL; сервер read-only — не пишет и не запускает код.
- Не заменяет `build` / `check` / `test.*` / `debug.*`.

### Приоритет

Сначала workspace и must-поток 1c-dev; bsl-search — корпус внешних примеров.
